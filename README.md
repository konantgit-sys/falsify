# falsify

Проверяет подписанный журнал записей — и, главное, проверяет **саму проверку**:
умеет ли она падать там, где обязана.

`verify` пересчитывает хеш записи, проверяет подпись Ed25519 над JCS-каноникой
(RFC 8785) и связь с предыдущей записью. `mutants` portит запись шестью способами —
и хорошая проверка обязана провалить все шесть. Если хоть один мутант прошёл,
проверка бесполезна, и инструмент скажет это прямо.
